# AEI-011: V0 Static Concept Demo

Status: Done

## Purpose

Build a static React page that explains the AI Energy Intelligence concept before the real proxy exists.

## Scope

- Show the product name and measurement-layer positioning.
- Explain the before-and-after story.
- Show fake summary metrics for tokens, cost, energy, and CO2.
- Show a simple architecture flow from client apps through proxy to provider and dashboard.
- Show a fake recent usage log table.

## Acceptance Criteria

- The page runs as a Vite React app in `apps/dashboard`.
- No backend, auth, database, or real API calls are required.
- The page builds successfully with `npm run build:dashboard`.
- The page is usable at desktop and mobile widths.
